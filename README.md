# Unlimited Enchant

Change and disable the maximum level of any registered enchantment on your server, whether from vanilla, a plugin, or a
data pack.

## Features

- Increase or decrease the maximum level, or disable, any registered enchantment
- New enchantments from plugins and data packs are added to the config automatically
- Change the maximum price for an operation in the anvil
- Make renames always cost the same regardless of how many times an item has been modified (including making it free)
- `/ue` commands for in-game configuration (enchantment changes require a restart to apply)

## Quick start

1. Put the jar in `plugins/` and start the server.
2. Edit `plugins/UnlimitedEnchant/config.yml`.
3. **Restart** the server.

> **⚠ Do not use `/reload` or PlugMan.** Enchantment levels are applied while the server starts up. This is due to how
> the game works and a full restart is the only way to apply changes.

## Documentation

Full config reference, commands, and permissions: **https://elephant1214.me/UnlimitedEnchant/**

Paper and Purpur, 1.21.4 – 26.3. Requires Java 21+.
